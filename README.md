# Food cottage

A responsive restaurant website: browse the menu, customise dishes, place orders, book a table and manage everything from an admin dashboard.

**Live demo:** https://YOUR-LINK.vercel.app

## Features

- Menu with search, category tabs, veg/spicy filters and sorting
- Dish page with size, spice, extras and notes
- Cart, checkout (delivery or pickup) and order tracker
- Table reservation
- Profile with order history and reorder
- Admin dashboard: order status, prices, availability, add dishes
- Light and dark mode, fully responsive

## Tech

React, Vite, Tailwind CSS, React Router

## Run locally

npm install
npm run dev

## Note

Data is sample data kept in the browser, so it resets on refresh. No backend yet.
